# YUVA Week 2 – Test Case Development

## Project Overview
This project focuses on developing and executing test cases for Mozilla Firefox as part of the Week 2 QA internship task.

## Objective
To verify basic browser functionality, navigation, tab management, bookmarking, browsing history, private browsing, invalid URL handling, file downloads, and page rendering.

## Testing Environment
- Browser: Mozilla Firefox
- Operating System: Windows
- Testing Type: Functional Testing

## Test Cases
The test cases cover:
- Firefox launch
- Opening a website
- Address bar search
- Back and forward navigation
- Page refresh
- Tab management
- Bookmarking
- Browsing history
- Private browsing
- Invalid URL handling
- File downloads
- Page resizing and rendering

## Test Evidence
Screenshots of the executed test cases are included in this repository.

## Conclusion
The test cases were executed to evaluate basic Mozilla Firefox functionality. Actual results and test statuses are documented in the submitted test case report.
